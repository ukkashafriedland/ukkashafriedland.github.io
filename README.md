# Ukkasha Fried Land – Online Menu & WhatsApp Ordering

Upload everything in this folder (index.html, ukkasha-menu.pdf, img/) to a new GitHub repository
and turn on GitHub Pages (Settings → Pages → Branch: main / root).
Site address will be: https://<your-username>.github.io/<repo-name>/

Edit shop settings at the top of the <script> in index.html (SHOP = {...}):
- whatsapp / phone, mapsUrl (paste the real Google Maps link)
- openTime / closeTime (e.g. "12:30" and "01:50") to show OPEN/CLOSED
- deliveryRates and minDeliveryFood
Menu items & prices are in MENU = [...] in the same file.
